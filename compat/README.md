# `compat/` — what a version number promises

`scripts/check-version.sh` holds nineteen literals across sixteen files
to `VERSION`. That proves the number is **stated**. This directory is
what makes it **earned**.

| File | What it is |
|---|---|
| `<version>.axsym` | the public surface that version published, one normalised row per name |
| `BREAKING` | every break declared against the version that makes it |
| `UNCOVERED` | public names the symbol stream cannot carry yet, as a set |

A baseline is generated by `tests/compat/verify-compat.py`, whose header
records why the AXSYM `@nid` is identity and the type plus effect row is
the contract — both measured rather than assumed.

Cutting a release adds a new `<version>.axsym` and leaves the previous
one in place; the history is the point. `docs/compatibility.md` is the
policy, and `scripts/check-compat.sh` is its keeper.
