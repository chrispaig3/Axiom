# Notes for agents working in this repository

## Documentation

Every Markdown page here follows one house style, set by the Axiom
website: short, direct and warm, written to the reader, examples before
explanation, and upfront about limits. That covers README, the language
reference, guides, specifications, design records and the READMEs in
subdirectories. The full guide is the `docs-style` skill,
`.claude/skills/docs-style/SKILL.md`. Load it before you write or edit
any `.md` file, including a page you are only adding one paragraph to.

The short version:

- Describe what is true now. History, dates and "used to" belong in
  `CHANGELOG.md`, which is append-only and keeps its own record.
- Keep one roadmap. Planned work and everything left before 1.0 live
  only in `docs/roadmap.md`. Other pages describe what is true now; a
  limit gets one "Not yet" line and a link to the roadmap. When work
  lands, update its roadmap row in the same commit.
- Don't scatter documentation. Extend the page that owns a topic
  instead of adding a thin new one. When a page's content moves, delete
  the old page in the same change and update its links, the gate lists
  and the website.
- Don't narrate CI gates or the document's own conventions in user
  pages. Cite evidence quietly: one "Tested by `tests/...`" line, not a
  story.
- No shouting in capitals, no stacked bold lead-ins, no spaced hyphens
  as dashes, no defensive "deliberately" or "not X but Y" phrasing.
- British spelling, sentence-case headings, ```` ```scheme ```` for
  Axiom code. Every example that declares `main` must compile.
- Keep headings that other files link to, or leave an
  `<a id="old-anchor"></a>` behind.
- In the specifications (`docs/memory-model.md`,
  `docs/macro-system.md`, `docs/error-model.md`), rule identifiers and
  status markers are never renamed, reused or dropped.
- `docs/stdlib-api.md` is generated by `examples/axdoc/axdoc.ax`.
  Change the generator, never the page.

Before committing a documentation change, run:

```bash
python3 scripts/lib/doc-style.py --axiom .axiom-bin/axiom path/to/page.md
AXIOM=$PWD/.axiom-bin/axiom ./scripts/check-doc-drift.sh
```

Build the compiler once with
`./scripts/bootstrap-from-seed.sh --install .axiom-bin`.
