# Every symbol a Windows Axiom executable may import, by name - one list
# for windows-x86_64 and windows-aarch64, whose runtime and platform
# module reach the same kernel32 names.
#
# This is the Windows half of check-freestanding.sh's second claim.
# Linux and macOS assert a NEGATIVE - no libc name among the imports;
# Windows has no syscall ABI, so its runtime must import SOMETHING, and
# the claim there is a POSITIVE: nothing outside this list. Every name
# here is one the emitted runtime, `stdlib/Sys/Platform.windows.ax` or
# `stdlib/Internal/WindowsLiveness.windows.ax` or the native command pool
# reaches by call where the other targets make a syscall, and the gate
# refuses a libc name on this list whatever it says (`libc_names`), so
# the list cannot launder one. It may shrink; it grows only in a
# reviewed diff.
#
# Large stack frames call `__chkstk`, which the emitted runtime defines
# for both architectures. It is not an allowed import: an executable
# must carry its own probe rather than depend on a compiler runtime DLL.

# The emitted runtime (core/codegen.ax, emitRuntimeMap /
# emitRuntimeWrite / emitRuntimeExit / emitWinEntry): one kernel32 call
# for each syscall the other targets make through inline asm.
VirtualAlloc             # mmap: the allocator's and the arena's chunks
GetStdHandle             # the fd-2 constant, and fds 0/1 in Sys/Platform.windows.ax
WriteFile                # write(2, ...) on the three trap paths and the backtracer
RtlCaptureStackBackTrace # the backtracer's frames on windows-x86_64, whose prologues keep no frame-pointer chain
AddVectoredExceptionHandler # the stack-overflow trap's handler, installed at entry
SetThreadStackGuarantee  # 64 KiB of every thread's stack kept for that handler
ExitProcess              # exit_group: ends every thread
GetCommandLineW          # the kernel's argv on the stack
GetEnvironmentStringsW   # argv[argc+1...]: the environment block

# stdlib/Sys/Platform.windows.ax, the console-and-process half.
ReadFile                 # read(fd, ...)
GetLastError             # errno, negated into the contract every caller tests

# stdlib/Sys/Platform.windows.ax, files and directories. `IO.ax` and
# `Sys.ax` reach these through the `platform*` shims where the other
# targets make the syscall named beside each.
CreateFileW                   # open: flags mapped to access, disposition and share mode
CloseHandle                   # close
SetFilePointerEx              # lseek, and the SEEK_END size probe
FlushFileBuffers              # fsync
SetEndOfFile                  # ftruncate, after SetFilePointerEx
LockFileEx                    # flock: one byte at 2^62 stands for the file
UnlockFileEx                  # flock(LOCK_UN)
DeleteFileW                   # unlink
MoveFileExW                   # rename, replacing an existing target as POSIX rename does
CreateDirectoryW              # mkdir
RemoveDirectoryW              # rmdir
GetFileInformationByHandleEx  # getdents (FileFullDirectoryInfo), and O_DIRECTORY's check
GetCurrentDirectoryW          # getcwd

# stdlib/Sys/Platform.windows.ax, processes. `Sys.ax` reaches these
# through the `platform*` shims where the other targets make the
# syscall named beside each.
CreateProcessW          # posix_spawn, or fork and execve: argv as one quoted command line
WaitForSingleObject     # wait4, and the zero-timeout poll behind sysChildExited and kill(pid, 0)
GetExitCodeProcess      # the exit code a wait reports
TerminateProcess        # kill, with exit code 128 + the signal
GetCurrentProcessId     # getpid
SetHandleInformation    # mark the three standard handles a child is given inheritable
SetStdHandle            # the descriptor 2 (and 1) swap sysRunPathErrTo and sysSpawnOutErrTo make

# Internal/WorkerProcess.windows.ax: bounded shared byte transports.
CreateFileMappingW      # unnamed page-file mapping, inherited by one worker
MapViewOfFile           # bounded parent and endpoint views
UnmapViewOfFile         # retire each process's own view

# Internal/WindowsCommandsNative.windows.ax: contain commands before
# their first instruction, and terminate them if their pool owner exits.
CreateJobObjectW        # one private cleanup job per command pool
SetInformationJobObject # JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE
InitializeProcThreadAttributeList # allocate the job-list launch attributes
UpdateProcThreadAttribute # assign the cleanup job during process creation
DeleteProcThreadAttributeList # release the native launch attributes
ResumeThread            # start a child after its cleanup owner is live

# The clock, sleep and entropy (`Sys/Platform.windows.ax`). A name with
# an `@dll` suffix is imported from that DLL rather than kernel32, and
# the gate makes that DLL's import library from these lines too.
QueryPerformanceCounter         # the monotonic clock's ticks
QueryPerformanceFrequency       # their rate, fixed at boot
GetSystemTimePreciseAsFileTime  # the wall clock, 100 ns ticks since 1601
Sleep                           # the sleep loop's wait, in milliseconds
ProcessPrng@bcryptprimitives    # entropy: the generator the kernel seeds

# Waiting on a word, memory and its locking (`Sys/Platform.windows.ax`).
VirtualFree                                   # munmap, MEM_RELEASE
VirtualLock                                   # mlock, for the secret store's pages
VirtualUnlock                                 # munlock
WaitOnAddress@api-ms-win-core-synch-l1-2-0    # the futex wait on a word
WakeByAddressAll@api-ms-win-core-synch-l1-2-0 # and its wake

# The console (`Sys/Platform.windows.ax` and the private guard-handle
# binding in `Internal/WindowsLiveness.windows.ax`): `isTerminal`,
# `termSize` and `termRaw`.
GetFileType                 # a console is a character device ...
GetConsoleMode              # ... that answers this; also raw mode's saved word
GetNumberOfConsoleInputEvents # validate console input before opening a private reader
DuplicateHandle             # private terminal guard handles survive File close
SetConsoleMode              # raw mode, and its restore
SetConsoleCtrlHandler       # process-owned Ctrl-C and Ctrl-Break handler
CancelSynchronousIo         # stop a pending reader before mode changes or close
GetConsoleScreenBufferInfo  # the window's rows and columns
GetTickCount64             # millisecond deadlines for mixed handle/socket waits

# Threads (codegen's `emitParThreadWin`, the thread half `parallel`
# takes where there is no `fork`).
CreateThread            # a binding's thread, on the image's own stack reservation
WaitForSingleObject     # its join

# Sockets (`Sys/Platform.windows.ax`), all from ws2_32.
WSAStartup@ws2_32        # Winsock 2.2, asked for by every socket open
WSAGetLastError@ws2_32   # the socket calls' own last error
WSASocketW@ws2_32        # socket(), without the overlapped attribute
bind@ws2_32
listen@ws2_32
accept@ws2_32
connect@ws2_32
send@ws2_32
recv@ws2_32
shutdown@ws2_32
setsockopt@ws2_32
getsockopt@ws2_32        # also the test that tells a SOCKET from a HANDLE
ioctlsocket@ws2_32       # FIONBIO: blocking or not
getsockname@ws2_32
getpeername@ws2_32
closesocket@ws2_32       # a SOCKET's close
WSAPoll@ws2_32           # the poller's wait
